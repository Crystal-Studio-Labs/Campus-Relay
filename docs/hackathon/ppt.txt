SLIDE 8 — OFFLINE-FIRST RESILIENCE: THE INDEXEDDB OUTBOX
--------------------------------------------------------------------
Headline:   LOCAL-FIRST ARCHITECTURE: WORKS WITH ZERO SIGNAL
Sub-head:   Client-side IndexedDB outbox queue, background sync, and idempotent deduplication.

ON-SLIDE CONTENT:
  • The Offline Reality: Hostels, basements, and remote campus gates frequently drop connectivity.
    Campus Relay treats offline as a standard operational state, not an error exception.
  • Client-Side Outbox Queue: When the network is severed, all case submissions, gate scans, and status
    updates write immediately to the browser's local IndexedDB outbox store.
  • Cryptographic Idempotency Keys: Every client action generates a UUIDv4 idempotency key locally;
    duplicate sync requests or network retries collapse safely into the exact same database record.
  • Automatic Background Replay: The service worker monitors network heartbeat. Once connectivity resumes,
    queued outbox actions replay seamlessly in strict causal sequence.
  • Transparent State Indicators: Users are never left wondering; the UI displays explicit sync indicators:
    [QUEUED LOCALLY] → [SYNCING] → [SYNCED TO SERVER] → [CONFLICT_RESOLVED].
